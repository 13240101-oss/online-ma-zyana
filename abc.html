📘 GitHub Pagesでのオンライン公開方法

このゲームは単一のHTMLファイル（index.html）で完結しているため、GitHub Pagesを使えば無料で誰でもWeb上に公開し、4台のパソコンからURLにアクセスして対戦できます！

ステップ 1：このHTMLファイルを保存する

このゲームのソースコードをコピーし、index.html という名前でパソコンに保存します。

ステップ 2：GitHubにリポジトリを作成してアップロード

  1. GitHub にログインし、右上の「＋」→「New repository」をクリック。
  2. Repository name（例：online-mahjong）を入力し、「Public」を選んで「Create repository」を押す。
  3. 「uploading an existing file」をクリックし、保存した index.html をドラッグ＆ドロップして「Commit changes」を押す。

ステップ 3：GitHub Pagesを有効化する

  1. リポジトリ上部の「Settings」タブ → 左メニューの「Pages」をクリック。
  2. 「Build and deployment」の Branch を main / / (root) に変更して「Save」を押す。
  3. 1〜2分後に画面上部に公開URL（https://ユーザー名.github.io/online-mahjong/）が表示されます！

ステップ 4：設定不要で4台対戦スタート！

公開したURLを4台のパソコンのブラウザで開き、ホストが「部屋を作る」で決めた同じパスワード（合言葉）を残り3台が「部屋に入る」に入力するだけで、特別なデータベース設定なしで直接オンライン接続されます！
